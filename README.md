# One Line a Day — PWA v6

新增配色主题：
- 极简黑白 / Minimal
- 马卡龙 / Macaron
- 多巴胺 / Dopamine
- 奶油手账 / Cream Journal
- 莫兰迪 / Morandi

其中：
- 奶油手账：米白、奶咖、灰蓝、豆沙，整体更像纸质手账
- 莫兰迪：灰蓝、灰绿、灰粉、灰紫，低饱和更安静

每种配色都可继续搭配：
- 跟随系统
- 浅色
- 深色

同时保留：
- 默认仅「我的一天」
- 「熹熹的一天」不在系统默认常用区块中
- 用户可在设置 → 常用区块标题中自行添加「熹熹的一天」
- 自定义常用区块
- 日历 / 全年 / 往年今日 / 搜索
- 备份导入导出

部署：
解压 ZIP，将全部文件上传到原 GitHub Pages 仓库根目录覆盖旧文件。
建议发布后用 ?v=6 打开一次。
