更新 GitHub Pages 后，如果手机桌面仍显示旧图标：
1. 用 Safari 打开新版本页面，建议网址末尾加 ?v=7。
2. 删除手机桌面上的旧快捷方式。
3. Safari → 分享 → 添加到主屏幕，重新添加。
iOS 可能会缓存旧的 Home Screen 图标，单纯覆盖 GitHub 文件后通常不会立即替换已经安装的旧图标。
