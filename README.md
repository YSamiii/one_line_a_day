# One Line a Day — PWA v10

新增 AI：
- 设置中可填写 Provider / Endpoint / Model / API Key
- 以后换兼容 Provider 只改设置，不用重新编写 App
- 单条记录可 AI 整理成一句话，并保留原文
- 全年页可批量整理：我的一天 / 熹熹的一天 / 全部区块
- 范围可选当前年份 / 当前月份 / 全部记录
- 可仅处理还没有 AI 版本的记录
- 可先预览前 10 条
- 三种风格：忠实精简 / 自然日记 / 超短一句
- API Key 只保存在本机；导出备份时不会导出 Key

保留 v9 月份跳转、v8 语言与筛选修复、五套主题和新版桌面图标。
