# One Line a Day — PWA

功能：
- 每天分别记录「我的一天」和「熹熹的一天」
- 每条最多 120 字
- 可选标签
- 月历查看/编辑历史记录
- 全年总览，可切换「一起 / 我的 / 熹熹」
- 往年今日
- 关键词和标签搜索
- 中文 / English / 跟随系统
- 浅色 / 深色 / 跟随系统
- 完整 JSON 备份导出/导入
- PWA，可部署到 GitHub Pages 后添加到 iPhone 主屏幕
- 当前版本数据仅保存在本机 localStorage

部署到 GitHub Pages：
1. 解压 ZIP。
2. 将解压后的所有文件上传到 GitHub 仓库根目录。
3. Repository → Settings → Pages。
4. Source 选择 Deploy from a branch。
5. Branch 选择 main，folder 选择 /(root)，保存。
6. 等待 GitHub Pages 地址生成后，用 Safari 打开。
7. iPhone Safari → 分享 → 添加到主屏幕。
